# Quorum

Quorum is an AI recruitment interview for software engineers, planned for the EchoSphere 2026 Agora Conversational AI Hackathon.

Candidates investigate and change a small application while an AI panel questions their decisions. The final assessment links their answers to code versions and test results that a reviewer can inspect and replay.

## Documentation

- [Product requirements](PRD.md)
- [Product requirements in Word](PRD.docx)

The PRD covers the interview experience, architecture, API, build plan, business model, and go-to-market approach.

## Planned stack

Next.js, TypeScript, Monaco Editor, Agora Conversational AI, FastAPI, E2B, SQLite, and React Flow.

## Status

Product specification complete. The application has not yet been implemented. Quorum is designed to support human review, not make automatic hiring decisions.
